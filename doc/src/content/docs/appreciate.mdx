# Appreciate

If you like <Rug client:load /> and want to support the project, here are a few ways to help:

- Star the repository on [GitHub](https://github.com/ashutosh1919/react-awesome-loaders)
- Share the project with other developers
- Open issues or pull requests to improve loaders and docs
- Subscribe to [Dev Sense on YouTube](https://www.youtube.com/c/DevSense19)

Thank you for supporting open source work.

# Contributing to Project

All kinds of contributions are welcome.

<Rug client:load /> is created with the help of what is available for free on the internet and hence it will always be available for free. This makes it an open source project and everyone is welcome to contribute.

## How can you contribute to this project?

You can contribute in the following ways:

- Propose new loader ideas
- Open pull requests to fix bugs
- Improve documentation
- Share the project with others

## Development setup

```bash
git clone https://github.com/ashutosh1919/react-awesome-loaders.git
cd react-awesome-loaders
npm install
npm run build
```

For the documentation site:

```bash
cd doc
npm install
npm run dev
```

## Code of conduct

Please be respectful and constructive in issues and pull requests.

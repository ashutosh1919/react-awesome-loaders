# Why use React Awesome Loaders

<Rug client:load /> is a library that focuses on making complex loading animations easy to configure.

In most situations, building simple loading animations using `css` properties is easy for a particular use case. Responsiveness for this can be handled with media queries with ease.

But what if we want to create complex animations and scale them? It takes a lot of effort and time to create such animations using only `css`. Moreover, customizing parameters like size, colors and speed through `css` is another problem.

<Rug client:load /> solves this problem by using advanced animation libraries like `gsap`, `zdog`, `three`, and `@react-spring/web`, which work based on physics. Responsiveness is handled using `react-responsive`. Customizing parameters like size and colors is handled through **CSS in JS** using `styled-components`.

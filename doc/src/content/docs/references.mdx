# References

Built using some awesome open source projects.

<Rug client:load /> uses modern libraries built for React. Here are the main ones.

## Dependencies for core loader components

- [**styled-components**](https://github.com/styled-components/styled-components): CSS-in-JS styling for loader components.
- [**gsap**](https://github.com/greensock/GSAP): JavaScript animation library.
- [**three**](https://github.com/mrdoob/three.js/): JavaScript 3D library.
- [**zdog**](https://github.com/metafizzy/zdog): Pseudo-3D engine for canvas and SVG.
- [**polished**](https://github.com/styled-components/polished): Color utilities for styled-components.
- [**jquery**](https://github.com/jquery/jquery): DOM utilities used by some loaders.
- [**react-responsive**](https://github.com/contra/react-responsive): Media queries in React.

## Dependencies for documentation website

- [**Astro**](https://astro.build): Static site generator for this documentation site.
- [**Starlight**](https://starlight.astro.build): Documentation theme for Astro.
- [**react-player**](https://github.com/cookpete/react-player): Embedded video player component.
- [**@react-spring/web**](https://github.com/pmndrs/react-spring): Spring physics based React animation library.
- [**@use-gesture/react**](https://github.com/pmndrs/use-gesture): Gesture utilities for React.

There are many other dependencies used internally. You can check them in `package.json` in the GitHub repository.
